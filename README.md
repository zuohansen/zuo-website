# Zuo Property Management website

The website for Zuo Property Management, a repair-first property manager for owners of single-family rentals and
multi-family rentals with up to four units.

Live site: https://zuohansen.github.io/zuo-website/

The whole site is one file, `index.html`, with four pages: Home, About us, Pricing and Contact. It needs no build
step. The contact form checks what people type, but it doesn't send anything yet.

This repository is published from another repository, so changes made here directly will be overwritten.
